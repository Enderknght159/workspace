# Workspace

تطبيق ديسكتوب لإدارة المكتب الإعلامي: أصول، مهام، مونتاج آلي عبر OpenCode، مراجعة بشرية، وأرشفة.

**الحالة:** التخطيط — لا يوجد كود بعد.

## الوثيقة

الخطة الكاملة والقرارات المعتمدة في [`plan/workspace-plan.md`](plan/workspace-plan.md).

## ملخص القرارات

- تطبيق ديسكتوب: Electron + React + TypeScript.
- محرّك معزول (قاعدة بيانات، طابور، عمليات) قابل للتشغيل بلا واجهة.
- لا تُضمَّن أدوات المونتاج؛ فحص بيئة وتجهيز موجّه عبر OpenCode.
- هوية أقراص مركّبة، ومسارات نسبية `(volume_id, rel_path)` فقط.
- مكتب محمول (Office) + أساليب كحزم بيانات + وصفات.
- صلاحيات بكلمة مرور للمكتب بدل حساب أدمن.
- جدولة ليلية، تحقق بشري إلزامي قبل النشر.

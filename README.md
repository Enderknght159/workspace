## المتطلبات

- **Windows 10/11** (المنتج يستهدف ويندوز أولًا).
- **Node.js 24+** للتطوير.
- **FFmpeg 6.1+** و**Python 3.10+** لتشغيل الوظائف الحقيقية (يفحصهما Doctor).
- **OpenCode** اختياري؛ بدونه يعمل الوضع التجريبي.
- مساحة حرة على قرص العمل (الحد الافتراضي: منع البدء تحت 40GB).

> `npm install` ينزّل Electron (~150MB). على شبكات بطيئة قد يحتاج وقتًا أو مرآة.

## البدء السريع

```bash
npm install
npm run dev        # Vite + tsc watch + Electron
```

أو بناء وتشغيل الإنتاج محليًا:

```bash
npm run build
npm start
```

أوامر أخرى:

```bash
npm test           # 33 اختبارًا للمحرّك والعقود
npm run typecheck  # فحص TypeScript للطبقتين
npm run dist       # مثبّت NSIS + نسخة portable
```

تشغيل المحرّك وحده (بلا واجهة):

```bash
npm run build:node
node dist/node/engine/host.js --office "D:\WorkspaceOffice" --port 45871
# يطبع سطر handshake فيه المنفذ والتوكن
```

مجلد المكتب الافتراضي: `%USERPROFILE%\Documents\WorkspaceOffice`، ويمكن تغييره بـ`WORKSPACE_OFFICE`.
في النسخة المحمولة (portable) يصبح بجانب الملف التنفيذي.

## البنية

```
src/
  shared/    عقود zod + أنواع + أخطاء عربية + آلات حالة (بلا Node/Electron)
  engine/    المحرّك: SQLite، الخدمات، الطابور، HTTP/SSE (بلا Electron)
  main/      Electron main: نافذة، Tray، دورة حياة المحرّك، تحديث
  preload/   جسر آمن (توكن + مسار API + أوامر نظام محدودة)
  renderer/  React 19 عربي RTL — بلا وصول للملفات
```

- **المحرّك عملية منفصلة** يتواصل معها الـmain والواجهة عبر `127.0.0.1` + Bearer token.
- **قاعدة البيانات مصدر الحقيقة**، والمجلدات انعكاس لها (`manifest.json` + مُصالِح).
- **لا مسار مطلق في قاعدة البيانات** — فقط `(volume_id, rel_path)`.
- **كل عملية مدمّرة** تمر بصلاحية وتُسجَّل في `audit_log`.

التفاصيل: [docs/architecture.md](docs/architecture.md) · [قرارات ADR](docs/adr) · [العقود](docs/spec/contracts.md) · [آلات الحالة](docs/spec/state-machines.md).

## تجربة سريعة ببيانات وهمية

بعد تشغيل التطبيق (أو المحرّك)، يمكن ملء المكتب بحدث ووظيفة جاهزة للمراجعة:

```bash
node scripts/seed-demo.mjs http://127.0.0.1:45871 devtoken
```

> السكربت للتطوير فقط. الوكيل التجريبي ينتج ملفات وهمية و`result.json` صالحًا لاختبار المراجعة.

## الأمان بصدق

- كلمة مرور المكتب تحمي **من الخطأ** لا من الخائن؛ من يعرفها يستطيع كل شيء.
- `scrypt` (N=32768) + 5 محاولات/10 دقائق + رمز استرداد يُعرض مرة واحدة.
- التوكن يُسلَّم عبر stdout إلى الـmain فقط، والواجهة تتلقاه من preload.
- **حدود الوكيل ليست صندوقًا رمليًا كاملًا**: قواعد shell وحدود المجلدات تقليل مخاطر لا عزل مطلق. العزل الحقيقي (مستخدم ويندوز منفصل + ACL) مدرج في خطة لاحقة.
- لا تُشغّل `--auto` على محتوى غير موثوق.

## ما تبقّى (باختصار)

1. التحقق من محوّل OpenCode على خادم حقيقي وتثبيت عقده.
2. اكتشاف تغيّر حرف القرص تلقائيًا عند الفحص.
3. مسار robocopy الفعلي للبطاقات البطيئة (المنفّذ حاليًا نسخ Node + هاش).
4. صور/فعاليات، حسابات مستخدمين، نشر عبر YouTube API، هجين بريمير.
5. مثبّت موقّع وتحديث تلقائي مربوط بمزوّد إصدارات.

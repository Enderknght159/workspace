# دليل الاستخدام

## 0. الحساب

عند أول تشغيل تظهر نافذة **«من يعمل الآن؟»** أعلى الشاشة. اختر مستخدمًا أو أضف واحدًا
(اسم + دور). لا كلمة مرور للحساب؛ الحماية تكون على الإجراءات الحساسة بكلمة مرور المكتب.
كل إنشاء/مراجعة/نشر/نقل يُسجَّل باسم المستخدم النشط. يمكن التبديل من الشريط العلوي في أي وقت،
ويمكن تنفيذ قرار المراجعة باسم مستخدم آخر من نفس الشاشة.

## 1. أول تشغيل

1. شغّل `Workspace.exe`.
2. افتح **الإعدادات ← التخزين** وسجّل قرصًا ساخنًا (مجلد موجود على قرص دائم، ليس بطاقة).
   - الاسم للعرض فقط.
   - تُكتب بصمة مخفية في جذر القرص: `.workspace-office\volume.json`.
3. افتح **الإعدادات ← البيئة** واضغط **فحص سريع**.
   - الأخضر = جاهز، الأصفر = تحذير، الأحمر = ناقص ويمنع الوظائف الآلية.
4. اسحب/اختر بطاقة من **الوارد**.

## 2. تفريغ بطاقة

1. **الوارد ← اختيار** مجلد البطاقة.
2. اضبط النوع والتاريخ والعنوان العربي والمعرّف اللاتيني.
3. **معاينة**: يعرض كل ملفات الوسائط. حدّد الملفات التي تريدها فقط.
   - يمكنك تفريغ مجموعة، ثم العودة وتفريغ مجموعة أخرى من نفس البطاقة إلى درس آخر.
   - «تحديد الكل» و«إلغاء الكل» متاحان.
4. اختر **وضع التفريغ**:
   - **نسخ**: يبقى المصدر كما هو (الافتراضي للمجلدات العادية).
   - **نقل**: يُحذف الملف من البطاقة **فقط بعد** نسخه وهاشه والتحقق منه ونقله إلى المكتب.
     البطاقة القابلة للإزالة تقترح «نقل» تلقائيًا.
5. **بدء التفريغ**: نسخ إلى `00_inbox` ثم تحقق بالهاش ثم نقل إلى `10_events/YYYY/MM/`.
6. البطاقة لا تُمس قبل التحقق. إذا فشل أي ملف لا يُحذف شيء من المصدر.
7. يمكنك **التراجع** عن نقل لاحقًا من صفحة الحدث: زر «إرجاع» على الأصل يعيد الملف
   إلى مساره الأصلي بعد التحقق (إن كان المصدر متاحًا ولم يوجد ملف بنفس الاسم).

## 3. وظيفة مونتاج OpenCode

من صفحة الحدث:

1. **وظيفة جديدة**.
2. اختر النوع (مونتاج/ريل/تفريغ/غلاف)، الأسلوب، والتنفيذ (يدوي أو تلقائي).
3. اليدوي يبدأ فورًا؛ التلقائي يحترم النافذة الليلية.
4. تابع التقدّم في صفحة الحدث أو من الشريط الجانبي.
5. عند الاكتمال تنتقل الوظيفة إلى **المراجعة**.

> الوضع التجريبي (Mock) ينتج ملفات وهمية. للنتائج الحقيقية فعّل OpenCode من **الإعدادات ← سير العمل**
> واضغط **اختبار الاتصال**. المحوّل يستخدم `opencode api` وينتظر انتهاء الجلسة.

## 3.5 مهام المونتاج في Premiere

1. من صفحة الحدث اضغط **«مهمة مونتاج»** أو افتح **المونتاج** من الشريط الجانبي.
2. اختر الحدث، النوع (كامل/ريل/خطبة)، والمصادر.
3. ينشئ Workspace:
   - `<Event>/edit/<task>/project.prproj` (ينشئه Premiere).
   - `<Event>/output/<task>/` للتصدير.
   - `<Event>/subtitles/<task>/` للترجمة.
4. اضغط **«إنشاء المشروع الآن»** ليشغّل Premiere بالمهمة، أو استخدم لوحة **Workspace Bridge**
   من `Window → Extensions` لتعمل تلقائيًا.
5. عند التصدير ضع الملف في مجلد التصدير، ثم **«تسجيل ملف التصدير»**. إن صدّرت إلى مكان آخر،
   اختر الملف وسيُسجَّل مع تحذير أنه خارج المكتب.
6. «حذف الخام» من صفحة الحدث ينقل المصادر إلى السلة (30 يومًا) ويبقي المخرجات.

## 4. المراجعة والنشر

1. افتح **المراجعة** واختر وظيفة.
2. شاهد المخرَج، ثم أكّد بنود قائمة التحقق الإلزامية.
3. **اعتماد** أو **إعادة للتعديل** (سبب إلزامي) أو **رفض نهائي**.
4. بعد الاعتماد: انشر من المنصة يدويًا، ثم ألصق الرابط واضغط **تسجيل النشر**.
5. لا نشر تلقائي. كل قرار يُسجَّل باسم المستخدم النشط.

## 5. الأرشيف

1. سجّل قرصًا **باردًا** من الإعدادات.
2. **الأرشيف ← معاينة** يعرض المرشحات (منشور منذ 7 أيام، بلا وظائف مفتوحة).
3. **أرشفة الآن**: نسخ → تحقق هاش → كتالوج بارد → نقل المصدر إلى `90_trash`.
4. لا حذف نهائي تلقائي. زر **إفراغ السلة القديمة** يحذف ما تجاوز 30 يومًا فقط.

## 6. النسخ الاحتياطي والتشخيص

- نسخة يومية تلقائية عند التشغيل + زر **نسخة الآن** (يحتفظ بـ14).
- **تنزيل حزمة التشخيص**: JSON فيه السجلات والفحص والإعدادات المنقّحة بلا مسارات ملفات.
- السجلات: `<Office>\logs\engine.jsonl` و`%APPDATA%\Workspace\logs\main.jsonl`.

## 7. كلمة مرور المكتب

- **الإعدادات ← الأمان ← تعيين كلمة مرور**.
- تُطلب للإجراءات الحساسة (اعتماد نهائي، نشر، تعديل إعدادات، أرشفة، تسجيل قرص).
- تُفتح 10 دقائق ثم تُقفل.
- احفظ **رمز الاسترداد** خارج الجهاز؛ لا يوجد «نسيت كلمة المرور».

## 8. عند حدوث مشكلة

| المشكلة | الإجراء |
|---|---|
| «المكتب مفتوح في نسخة أخرى» | أغلق النسخة الأخرى. إن كان التطبيق انهار، احذف `locks\office.lock`. |
| القرص غير موصول | وصّله ثم **الإعدادات ← التخزين ← إعادة فحص**. |
| فشل التحقق من النسخة | لا يُحذف المصدر. جرّب قارئ بطاقة آخر ثم أعد التفريغ. |
| الوظائف الآلية لا تبدأ | افتح الفحص؛ غالبًا FFmpeg أو Python ناقص. |
| OpenCode غير متاح | شغّل الخادم وسجّل الدخول، أو استخدم الوضع التجريبي. |
| قاعدة بيانات تالفة | استعد أحدث نسخة من `<Office>\backups`. |

## 9. مفاتيح ومسارات

| العنصر | المسار |
|---|---|
| المكتب | `%USERPROFILE%\Documents\WorkspaceOffice` (أو `WORKSPACE_OFFICE`) |
| قاعدة البيانات | `<Office>\data\workspace.db` |
| الأساليب | `<Office>\styles\<id>\style.json` |
| السجلات | `<Office>\logs\engine.jsonl` |
| النسخ | `<Office>\backups` |
| البطاقة | `<HotRoot>\00_inbox\<batch>` ثم `10_events` |
| السلة | `<HotRoot>\90_trash` |
| الأرشيف | `<ColdRoot>\WorkspaceCold` |

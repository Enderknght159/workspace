## ترتيب البناء (من الخطة)

```
الكتالوج والحالة ← الطابور والتحقق ← الوكيل ← الواجهة ← الأتمتة الكاملة
```

## قرارات اتخذتها ضمن المرونة الممنوحة

1. **Electron 45 + Node 24 + React 19 + Vite 8**، TS 5.9 (لا 7.0 حديثًا).
2. **حزمة واحدة بطبقات** بدل مونوريبو (ADR 0003).
3. **المحرّك عملية منفصلة** بـHTTP+SSE (ADR 0001/0004).
4. **`node:sqlite` خلف واجهة سائق** (ADR 0002).
5. **واجهة عربية RTL، اسم لاتيني**، بلا مكتبة UI خارجية — مكوّناتنا.
6. **OpenCode adapter + mock adapter** حتى لا يتوقف التطوير على حساب/خادم.
7. **السجلات JSONL محلية** بدل pino (اعتماد أقل، نفس الفائدة).
8. **نسخ البطاقة بـNode افتراضيًا مع مسار robocopy**، لأن Node أقبل للاختبار.

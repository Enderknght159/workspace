## خارج نطاق v0.1 (معلن)

الأرشفة التلقائية المجدولة، نشر YouTube API، هجين بريمير عبر MCP،
حسابات متعددة/تسجيل دخول، وضع الكشك، صور وفعاليات، Playground للأساليب.

## قرارات تنفيذ اتُّخذت ضمن المرونة الممنوحة

1. **Electron + React 19 + Vite 8 + TypeScript 5.9**.
2. **حزمة واحدة بطبقات** بدل مونوريبو (ADR 0003).
3. **المحرّك عملية منفصلة** بـHTTP+SSE وتوكن (ADR 0001/0004).
4. **`node:sqlite` خلف واجهة سائق** قابلة للاستبدال (ADR 0002).
5. **واجهة عربية RTL** بلا مكتبة UI خارجية.
6. **Mock + OpenCode adapter** لفصل التطوير عن توفر الوكيل.
7. **سجلات JSONL** بدل pino (اعتماد أقل).
8. **نسخ Node + هاش** بدل robocopy في v0.1 (أسهل للاختبار؛ robocopy في القائمة).

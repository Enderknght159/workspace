# ADR 0003 — حزمة واحدة، طبقات مفصولة

**التاريخ:** 2026-11-04
**الحالة:** معتمد

## السياق
المشروع قابل للتعديل من شخص واحد غالبًا. مونوريبو كامل (workspaces متعددة) يضيف خطوات بناء وحلّ حزم ونسخ إصدارات لا تُشترى.

## القرار
حزمة npm واحدة (`workspace`) مع مجلدات `src/shared`, `src/engine`, `src/main`, `src/preload`, `src/renderer` وثلاث عمليات بناء فقط:
- `tsc` لـ shared + engine + main (NodeNext, ESM).
- `esbuild` للـpreload (CJS).
- `vite` للواجهة.

## لماذا لا يكسر الحدود
الحدود تُفرض بالاستيراد النسبي (`../../shared/...`) وباختبار معماري يفحص كل ملف، وليس بحدود الحزم. الفائدة: بناء أسرع، لا `dist` متداخلة، ولا نسخ إصدارات.

## ما نتنازل عنه
لا نشر مستقل للمحرّك على npm. غير مطلوب: المشروع تطبيق واحد.

# ADR 0002 — SQLite عبر طبقة محرّك قابلة للاستبدال

**التاريخ:** 2026-11-04
**الحالة:** معتمد

## السياق
الخطة تعتمد `node:sqlite` المدمجة في Node 24 لتجنّب الوحدات الأصلية وتعقيد التغليف. لكن Electron يحمل نسخة Node خاصة به، وقد لا تكون `node:sqlite` متاحة فيها بنفس القدر.

## القرار
1. كل الوصول لقاعدة البيانات يمر عبر واجهة `SqliteDriver` صغيرة في `src/engine/db/driver.ts`.
2. التنفيذ الافتراضي `NodeSqliteDriver` يستخدم `node:sqlite`.
3. إن فشل تحميلها (نسخة Electron أقدم)، يرمي خطأ واضحًا في التشخيص، ويكون البديل المستقبلي `better-sqlite3` خلف نفس الواجهة دون تغيير أي خدمة.
4. اختبار `db/driver.test.ts` يتحقق من أن كل SQL المستخدم متوافق مع SQLite القياسي (بلا ميزات خاصة بمشغّل).

## العواقب
- لا تستخدم أي خدمة `DatabaseSync` مباشرة.
- الترحيلات SQL قياسي + جدول `schema_migrations` بأنفسنا.
- التحقق من توفر `node:sqlite` داخل Electron جزء من فحص أول تشغيل (Doctor).

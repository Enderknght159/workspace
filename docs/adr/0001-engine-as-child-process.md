# ADR 0001 — المحرّك عملية منفصلة

**التاريخ:** 2026-11-04
**الحالة:** معتمد

## السياق
الخطة تشترط أن يكون المحرّك وحدة Node لا تستورد Electron، قابلة للتشغيل headless، وأن تبقى الواجهة بلا وصول للملفات.

## القرار
يعمل المحرّك كعملية Node منفصلة (`src/engine/host.ts`)، يتواصل معها الـmain عبر HTTP محلي + SSE على `127.0.0.1` بمنفذ عشوائي وتوكن عشوائي.

## الأسباب
- يمنحنا حدًا حقيقيًا بين الواجهة والملفات، لا مجرد اتفاق.
- يمكن اختبار المحرّك كاملًا بلا Electron، وتشغيله على جهاز بلا واجهة.
- فشل المحرّك لا يُسقط النافذة، والعكس صحيح.
- لا حاجة لتمرير كل نوع عبر IPC يدويًا.

## التكاليف
- عملية إضافية (~40–60MB RAM).
- إدارة دورة حياة (بدء، مراقبة، إعادة تشغيل، إيقاف آمن).
- التوكن والمنفذ يجب ألا يتسرّبا إلى أي طرف ثالث.

## البديل المرفوض
تشغيل المحرّك داخل main: أبسط، لكنه يخالف شرط العزل ويجعل الاختبار الكامل يتطلب Electron.

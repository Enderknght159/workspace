# ADR 0004 — عقد HTTP محلي + SSE

**التاريخ:** 2026-11-04
**الحالة:** معتمد

## القرار
- كل الطلبات: `Authorization: Bearer <token>`.
- الاستجابة خطأ: `{ "error": { "code", "message", "action", "details?" } }` بحالة HTTP مناسبة.
- البث: `GET /api/stream` بـSSE، أحداث باسم النوع و`data` JSON.
- لا GraphQL، لا WebSocket.

## الأسباب
SSE أبسط، يمر عبر fetch، ويعيد الاتصال تلقائيًا. الحجم المتوقع للأحداث صغير (حالة وظائف وتقدّم).

## قواعد
- كل حدث يحمل `seq` و`at`، ويُرسل `hello` عند الاتصال لإعادة المزامنة.
- الواجهة تعيد جلب القائمة عند `*.updated` بدل تطبيق تحديثات جزئية هشّة.
- أي endpoint جديد يُضاف إلى `shared/contracts.ts` أولًا (مخطط zod)، ثم ينفّذ.
